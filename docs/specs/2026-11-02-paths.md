# Paths — spec

Settled 2026-11-02 in a design interview with the owner. Roadmap: KQ42 (phase 1), KQ43 (phase 2),
KQ44 (phase 3).

A **path** is an ordered list of existing quizzes ("Road to Software Architect"). Each quiz is a
step. Finishing a step suggests the next one, and the path has its own page showing what is done,
what is left and what still needs perfecting.

## Phase 1 (KQ42)

### Name and URLs
- The concept is called **Path** in the UI. Titles may say "Road to …".
- Path page: `/p/<slug>`. List of all paths: `/paths`.

### Creating a path
- A **path file** (YAML or JSON, like a quiz file) with `kind: path`. Accepted by `/upload` and by
  the seed import from `seeds/`.
- Steps reference quizzes **by slug** in uploaded files, and **by title** in seed files (matched
  among quizzes owned by the seed author, because seed slugs get a random suffix at import).
- Any **public** (not hidden) quiz can be a step, including other people's quizzes.
- At most **100 steps**. A quiz appears at most once in a path.
- A path upload counts against the **same upload limit** as quizzes (`UPLOAD_LIMIT`, 10/hour, key
  `upload:<userId>`).
- **Immutable** once published, like quizzes. Re-uploading creates a new path. Seed paths dedupe by
  title under the seed author, like seed quizzes.

### Progress (signed-in players only, from KQ40 tiers)
- A step is **done** with any pass (bronze or better), **to perfect** when its best tier is bronze or
  silver, **perfected** when gold.
- Path ribbon: **bronze** when every live step is passed, **silver** when every live step is silver
  or better, **gold** when every live step is gold. No ribbon otherwise, or for a path with no live
  steps.
- Guests see paths and the Continue button, without status marks.

### Path page
- Ordered live steps with each step's status and best tier, overall progress (done / perfected /
  left), the path ribbon, and a **Continue** button.
- Continue goes to the first live step not done. When every step is done it reads **Perfect next**
  and goes to the first step that is not gold. When every step is gold there is no button. Guests:
  Continue goes to the first step.
- Step links go to the quiz's run page with `?path=<pathSlug>`.

### Suggestions
- **Run summary**: after finishing a quiz that belongs to paths, show "Next in <path>: <quiz>". If the
  run page was opened with `?path=<slug>` and that path contains the quiz, show only that path.
  Otherwise list up to **3** paths. A quiz that is the last live step of a path shows "Last step of
  <path>" with a link to the path page.
- **Quiz page**: a quiet line per path, "Step 3 of 41 in <path>", linking to the path, with previous
  and next step links.
- **Catalog row**: "Road to Architect · 16/41" (the step's position / live step count, not progress),
  plus "+N" when the quiz is in more paths, linking to the first path.

### Browsing
- A **Paths** strip above the catalog's quiz list (newest first, up to 6), with a "See all" link.
- A `/paths` page listing every path, paginated like the catalog, and a **Paths** link in the
  header nav.
- Path cards (strip and `/paths`) show a signed-in player's path ribbon.

### Hidden and deleted quizzes
- A step whose quiz is deleted disappears (the step row cascades). A step whose quiz is hidden is
  skipped at read time. Numbering and counts use live steps only, so a path never becomes
  impossible to finish. A path with no live steps shows an empty state and no Continue.
- Hidden paths (`is_hidden`) are excluded everywhere, like hidden quizzes.

### First paths (seed files)
- **Road to Software Architect**: the 41 `Architect Roadmap NN` quizzes in order.
- **AWS Cloud Practitioner**: the 25 `AWS Cloud Practitioner NN` section quizzes in order, then the
  200-question mock exam.
- They reach production only when the owner approves the push.

## Phase 2 (KQ43) — in-app path builder
An authoring UI that produces the same data as a path file. Built close to the quiz editor (KQ04),
since both are editor work. Details to be settled when it starts.

## Phase 3 (KQ44) — path from a tag
"Create a path from the quizzes tagged X": produces a normal, editable path (one source of truth),
never a live tag-derived grouping. Depends on KQ43 for the editing.
